# SPEC — бот-контентщик для канала STORY | TEAM

## Что строим

Бот, который раз в сутки собирает исторические фотографии из открытых архивов,
готовит из них посты в формате канала, отдаёт редакторам на отбор в групповой чат
и публикует одобренное в канал по расписанию.

Бот **не придумывает факты**. Он переводит и переформатирует то, что есть
в метаданных источника.

---

## Стек

| Слой | Чем | Почему |
|---|---|---|
| Язык | TypeScript | один язык на весь проект |
| Telegram | grammY | есть адаптер под serverless |
| Расписание | GitHub Actions cron | бесплатно, сервер не нужен |
| База | Supabase Postgres | бесплатно, коммерция разрешена |
| Вебхук | Supabase Edge Function | там же, где база |
| LLM + vision | Gemini Flash | 1500 запросов/сутки бесплатно |

Всё бесплатное. Платных сервисов в проекте быть не должно.

### Два запрета

1. **Не привязывать карту к Google Cloud проекту с Gemini.** Включение биллинга
   удаляет бесплатный тариф целиком, и вызовы начинают тарифицироваться
   с первого токена.
2. **Не хранить изображения у себя.** Только URL и хэш. Скачиваем в момент
   публикации.

## Что завести до начала

- Бот в @BotFather → `BOT_TOKEN`
- Бота добавить в канал админом с правом публикации
- Бота добавить в рабочий групповой чат
- Проект в Supabase → `SUPABASE_URL`, `SUPABASE_SECRET_KEY` (новый формат `sb_secret_...`, не легаси `service_role`)
- Ключ в Google AI Studio → `GEMINI_API_KEY` (без карты!)
- `CHANNEL_ID`, `EDITORS_CHAT_ID`, список `EDITOR_USER_IDS`

Всё — в GitHub Secrets и в переменные окружения Supabase. В коде секретов нет.

## Схема базы

```sql
create table candidates (
  id            bigserial primary key,
  source        text not null,          -- 'loc' | 'bundesarchiv' | 'nara'
  source_id     text not null,          -- id записи в архиве
  source_url    text not null,          -- ссылка на карточку в архиве
  image_url     text not null,
  image_hash    text not null,          -- dHash, hex
  raw_title     text,                   -- исходный заголовок, как есть
  raw_desc      text,                   -- исходное описание, как есть
  raw_lang      text,                   -- 'en' | 'de' | ...
  year          int,
  place         text,
  caption_html  text,                   -- готовая подпись, HTML
  quote_kind    text,                   -- 'observation' | 'context'
  tags          jsonb,                  -- {period, region, subject}
  score         int,                    -- 0-100 от vision
  license       text,                   -- 'PD' | 'CC-BY-SA' | ...
  attribution   text,                   -- строка атрибуции, если нужна
  status        text not null default 'new',
                -- new | shown | approved | rejected | published | failed
  shown_at      timestamptz,
  published_at  timestamptz,
  channel_msg_id bigint,
  created_at    timestamptz default now(),
  unique (source, source_id)
);

create index on candidates (status);
create index on candidates (image_hash);

-- хэши всего, что уже выходило в канале (включая бэкфилл архива)
create table seen_hashes (
  image_hash text primary key,
  origin     text,              -- 'backfill' | 'published'
  created_at timestamptz default now()
);

-- отметки о том, что процессы живы
create table heartbeats (
  job        text primary key,  -- 'collector' | 'publisher'
  last_ok    timestamptz,
  last_error text
);
```

## Интерфейс адаптера источника

Каждый источник — отдельный файл, один общий интерфейс. Добавление источника
не должно трогать ничего, кроме конфига.

```ts
type RawItem = {
  sourceId: string;
  sourceUrl: string;
  imageUrl: string;
  title?: string;
  description?: string;
  lang: string;          // язык метаданных
  year?: number;
  place?: string;
  license: string;
  attribution?: string;
};

interface SourceAdapter {
  name: string;
  fetch(limit: number, cfg: SourceConfig): Promise<RawItem[]>;
}
```

Адаптеры первой версии: `loc`, `bundesarchiv`.
Позже: `nara`, `europeana`, `pastvu`.

## Конфиг

Один файл `config.yaml` в корне. Меняем поведение — правим его, не код.

```yaml
sources:
  loc:
    enabled: true
    weight: 50           # доля в дневной выборке
    queries: ["world war", "1930s", "street life"]
  bundesarchiv:
    enabled: true
    weight: 50
    categories: ["1939", "1940", "1941"]

collect:
  raw_limit: 150         # сколько тянем из архивов
  prefilter_keep: 30     # сколько доживает до vision-скоринга
  daily_candidates: 10   # сколько уходит редакторам
  min_image_width: 700

publish:
  times: ["09:00", "12:30", "15:00", "18:00", "21:00"]
  timezone: "Europe/Moscow"
  min_queue_warning: 5
  auto_publish: false    # true = публиковать без аппрува

balance:
  max_same_tag_per_week: 3   # не долбить одну тему

filters:
  stop_words: ["execution", "corpse", "mass grave", "atrocity"]
  block_nazi_symbols: true

glossary:
  "Königsberg": "Кёнигсберг"
  "Guards Rifle Division": "гвардейская стрелковая дивизия"
  "Sherman": "Шерман"

channel:
  id: "@Story_Teams"
  signature: "STORY | TEAM"
  signature_url: "https://t.me/Story_Teams"
```

## Формат поста

```html
<b>{Подлежащее}</b> {описание, часть, место, контекст}. <i>{год} год.</i>

<blockquote>{дополнительный факт или деталь}</blockquote>

<a href="{signature_url}">{signature}</a>
```

Жирным — только подлежащее, одно-два слова. Год курсивом в конце.
`parse_mode: HTML`. Лимит подписи под фото — 1024 символа.

Если лицензия требует атрибуции (CC-BY-SA) — строка источника добавляется
автоматически перед подписью канала.

### Примеры (эталон стиля)

> **Солдаты-мусульмане** Российской императорской армии на утренней молитве. *1915 год.*
> > По разным данным, общая численность мусульман в армии Российской империи во время Первой мировой войны составляла от 800 тысяч до 1,5 млн человек.

> **Танкисты** 61-й гвардейской Свердловской танковой бригады у танка Т-34-85 № 3-716 с личным именем «Партизан». *1945 год.*
> > Надпись на стволе пушки — «Победа за нами». У машины отсутствует третий каток ходовой части.

## Промпты

### Скоринг (vision)

Вход: изображение. Выход: JSON `{score: 0-100, tags: {...}, unsafe: bool}`.

Критерии: выразительность кадра, необычность сюжета, читаемость деталей,
пригодность для публичного канала. `unsafe: true` при телах, казнях,
графическом насилии, нацистской символике.

### Генерация подписи

Вход: `raw_title`, `raw_desc`, `year`, `place`, `lang`, глоссарий.

Жёсткие правила в промпте:

1. **Не добавлять фактов, которых нет во входных данных.** Нет точной даты —
   пишем «начало 1943», а не выдумываем число.
2. Топонимы — в названии, актуальном на дату снимка.
3. Соблюдать глоссарий дословно.
4. Исходные описания Бундесархива могут быть пропагандистскими, ошибочными
   или предвзятыми — переписать нейтрально, оценочные формулировки убрать.
5. Цитата: если факт виден на самом фото — `quote_kind: observation`.
   Если это внешний контекст — `quote_kind: context`.
6. Few-shot примеры из блока «Формат поста» — держать регистр речи.

Выход строго JSON, без обёрток и без markdown.

### Валидация после генерации

- год из подписи присутствует во входных метаданных — иначе брак;
- длина подписи ≤ 1024 символа;
- HTML валиден и содержит только `b`, `i`, `blockquote`, `a`.

Брак не отправляем редакторам, помечаем `status = failed`.

## Команды бота

Работают только для `EDITOR_USER_IDS`. От всех остальных — молча игнорировать.

| Команда | Где | Что делает |
|---|---|---|
| `/ok` | реплай на кандидата | в очередь публикации |
| `/skip` | реплай на кандидата | в отказ |
| `/quote <текст>` | реплай | заменить только цитату |
| *реплай текстом* | реплай | заменить подпись целиком |
| `/queue` | чат | сколько постов в очереди |
| `/undo` | чат | удалить последний опубликованный |

Правку принимаем с телеграмным форматированием: читаем `message.entities`
и конвертируем в HTML один в один. Редакторы не пишут теги руками.

## Этапы

Делать строго по одному. Каждый этап заканчивается проверяемым результатом.

### Этап 0 — каркас
Репозиторий, TypeScript, конфиг-лоадер, клиент Supabase, миграции.
**Готово когда:** `npm run migrate` создаёт таблицы.

### Этап 1 — dHash и дедуп
Функция хэша (grayscale → 9×8 → сравнение соседних пикселей → 64 бита).
Проверка на коллизии по расстоянию Хэмминга.
**Готово когда:** одно фото в двух размерах и в ч/б даёт расстояние ≤ 5.

### Этап 2 — бэкфилл архива канала
Скрипт разово проходит `t.me/s/Story_Teams`, качает все фото,
считает хэши, пишет в `seen_hashes` с `origin = 'backfill'`.
**Готово когда:** в таблице ~4400 записей.

### Этап 3 — адаптеры источников
`loc` и `bundesarchiv` по общему интерфейсу. Дешёвый префильтр:
нет года / нет места / картинка мелкая / стоп-слово → выкинуть.
**Готово когда:** `npm run collect -- --dry` печатает 30 кандидатов.

### Этап 4 — скоринг и подписи
Gemini Flash: сначала vision-скоринг выживших после префильтра,
потом генерация подписи для топ-10. Валидация. Запись в `candidates`.
**Готово когда:** в базе 10 кандидатов с готовым `caption_html`.

### Этап 5 — отправка редакторам
Крон-воркфлоу раз в сутки. Отправка 10 сообщений в групповой чат:
фото + готовая подпись + служебная строка (источник, тип цитаты, id).
Балансир по тегам. Запись heartbeat.
**Готово когда:** утром в чате лежат 10 карточек.

### Этап 6 — вебхук и аппрув
Supabase Edge Function, вебхук grammY. Команды из таблицы выше.
Вайтлист редакторов.
**Готово когда:** `/ok` переводит кандидата в `approved`.

### Этап 7 — публикатор
Крон каждые 15 минут: если наступил слот из `publish.times` и очередь
не пуста — публикуем верхний, пишем `channel_msg_id`, переносим хэш
в `seen_hashes`, шлём подтверждение в чат со ссылкой на пост.
Предупреждение при `min_queue_warning`.
**Готово когда:** пост выходит сам в 09:00.

### Этап 8 — heartbeat
Проверка: если `collector.last_ok` старше суток — сообщение в чат
с текстом ошибки. Отдельный воркфлоу раз в неделю трогает репозиторий,
чтобы GitHub не отключил расписания за неактивность.

## Чего не делать

- Своей веб-админки — Telegram уже интерфейс.
- Хранения изображений у себя — только ссылки.
- Обучения моделей на реакциях — собирать данные да, обучать нет.
- Подтягивания «интересных фактов» из внешнего поиска — прямой путь к вранью.
- Reddit — с мая 2026 бесплатного доступа нет, регистрация приложений закрыта.
- Любых платных сервисов.
