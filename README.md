# STORY | TEAM — бот-контентщик

Бот раз в сутки собирает исторические фотографии из открытых архивов,
готовит посты в формате канала, отдаёт редакторам на отбор в групповой чат
и публикует одобренное в канал по расписанию.

Полная спецификация — в [SPEC.md](SPEC.md).

## Стек

TypeScript · grammY · GitHub Actions cron · Supabase (Postgres + Edge Functions) · Gemini Flash.
Всё бесплатное; платных сервисов в проекте нет.

## Запуск

1. Скопировать `.env.example` в `.env` и заполнить (см. комментарии в файле).
2. `npm install`
3. `npm run migrate` — создаёт таблицы в Supabase (нужен `SUPABASE_DB_URL`).

Поведение бота настраивается в `config.yaml`, код для этого трогать не нужно.

## Скрипты

| Команда | Что делает |
|---|---|
| `npm run migrate` | применяет миграции из `migrations/` (идемпотентно) |
| `npm run typecheck` | проверка типов без сборки |
